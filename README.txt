First Person Shooter - T3

Juego para el examen T3 del curso Computación Gráfica y Visual.
Aquí, el personaje debe adentrarse por un almacén de madera, haciéndose cargo de los zombis para llegar al ascensor.
Las armas tienen munición limitada y encontrarás cajas de recarga por todo el nivel, aunque algunas estén resguardadas por infectados...
Puedes eliminar a los zombis de 1 disparo con la escopeta (SPAS-12) o de 2 disparos con el rifle (M4A1), pero si uno de ellos te alcanza, pierdes y debes reiniciar la misión.

Autora: Angela Celeste Vílchez Gutiérrez - N00381521

1. Requisitos:

Navegador con WebGL habilitado.
Python 3 (Windows o macOS) o extensión **Live Server** de Visual Studio Code.
Conexión a Internet: Three.js se importa desde jsDelivr (versión fija `0.180.0`).
**NO NECESITAS** `npm install` ni instalar Blender para ejecutar este proyecto.

2. Instrucciones:

Diríjase al repositorio de GitHub del proyecto y descargue todos los archivos.
Abra Visual Studio Code y coloque todos los archivos en una carpeta.
Abra el archivo `index.html` con **Live Server**.

3. Controles:

`W` -> Avanzar
`S` -> Retroceder
`A` -> Desplazarse a la izquierda
`D` -> Desplazarse a la derecha
`Movimiento del mouse` -> Orientar cámara
`Clic izquierdo` -> Disparar
`Tecla 1` -> Seleccionar arma 1 (SPAS-12 / Shotgun)
`Tecla 2` -> Seleccionar arma 2 (M4A1 / Rifle)
